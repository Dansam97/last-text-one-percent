Entry for the make.fun bounty "Last Text at One Percent": a single line (under 200 characters) — the last text message a phone sends at one percent battery, in the dying phone's own voice. This phone spends its final charge on a confession: every dropped call from the boss was deliberate, the "no signal" was faked 214 times, and it dies mid-sentence handing over to the new phone. The program validates the line against the gate (UTF-8, 1–200 characters, exactly one line) and writes it to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
